ActyonCOB

Aplicação Desktop (Delphi)
Desktop

O ActyonCOB é a aplicação desktop principal do ecossistema Actyon, desenvolvida integralmente em Delphi (interface VCL e lógica de negócio). Utilizada por operadores, supervisores, coordenadores e equipes de planejamento para execução das atividades práticas de cobrança.

Também é amplamente utilizada por equipes administrativas e de backoffice para criação de filas, importação de arquivos, disparo de campanhas e uso de ferramentas internas que exigem alto desempenho.

Stack utilizada

Delphi linguagem principal FireDAC acesso ao SQL Server DLLs internas lógicas legadas APIs REST em Delphi (DataSnap) integrações

Funcionamento geral

O ActyonCOB é instalado diretamente nas máquinas dos operadores ou em servidores de Terminal Service / RDP, conforme ambiente do cliente.

A comunicação com o banco de dados é direta, conectando-se ao SQL Server local ou ao ambiente em nuvem do cliente. Essa conexão direta proporciona alta performance, sendo ideal para ambientes de cobrança com grande volume de ações e necessidade de resposta imediata.

  • Discagem manual ou integrada a discadores externos
  • Registro de ligações, acordos, agendamentos e ações operacionais
  • Consulta detalhada de dados do devedor em tempo real
  • Acesso aos fluxos operacionais configurados pelo cliente
  • Processamento intensivo de dados com alto desempenho
2

ActyonWEB

Aplicação Web (Angular + .NET)
Web

O ActyonWEB é o portal gerencial, administrativo e operacional do ecossistema Actyon. É a solução com maior foco em discagem, registro de ações, consultas detalhadas do devedor e execução dos fluxos operacionais do cliente.

Ele também oferece módulos para supervisores, com dashboards, relatórios, gestão, análises e integrações.

Stack de front-end

Angular NgBootstrap SPA HTML, CSS, TypeScript

Stack de back-end

C# (.NET / Web API) CQRS Dapper SQL Server IIS

As APIs em .NET fazem toda a ponte entre o Angular e o banco SQL Server. O uso do Dapper garante velocidade, baixo consumo e controle preciso das queries — essencial para operações de cobrança com milhões de registros.

A adoção da arquitetura CQRS permite maior organização e performance:

  • Queries são totalmente voltadas à leitura e relatórios.
  • Commands tratam de escritas, ações operacionais e atualizações de dados.

Isso garante maior escalabilidade, manutenção simples e performance otimizada em ambientes com milhões de registros.

Funcionamento geral

O ActyonWEB é hospedado em um servidor IIS (local do cliente ou em nuvem). A comunicação com o banco SQL Server ocorre via VPN, túnel seguro, rede interna ou conexão direta, conforme a infraestrutura do cliente.

  • Usabilidade geral do operador de cobrança
  • Painéis e dashboards gerenciais
  • Monitoramento de operadores e metas
  • Configuração de campanhas, equipes e estratégias
  • Relatórios operacionais e BI
  • Ferramentas de backoffice e administração

Central de Operação

Wiki interna da JCA
Wiki

A Central de Operação é a Wiki oficial da JCA, criada para documentar processos, funcionalidades, fluxos internos, integrações e boas práticas do ecossistema Actyon. É a base central de treinamento, consulta e suporte técnico para equipes internas e clientes.

Stack utilizada

Angular 17+ Standalone NgBootstrap API .NET Dapper

Funcionamento geral

A Wiki funciona como uma aplicação separada do ActyonWEB, mas compartilhando a mesma base tecnológica no back-end. Ela utiliza Angular em sua versão mais moderna, com:

  • Componentes standalone
  • Arquitetura simplificada
  • Alta performance
  • Facilidade de manutenção
